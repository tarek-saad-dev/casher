# Onboarding analytics (#364)

Operator-only /platform/onboarding-analytics; protected GET, no-store. Rolling 7/30/90-day cohort by PublicSignupRegistration.CreatedAt, real salon only. Existing rows represent persisted submissions, not visits or every attempt. Status is current, not historical. Setup funnel is cumulative branch completeness, catalog, assigned active employee, historical day and shift at a qualifying branch. Not a claim of current subscription or live readiness. Independent first retained sale and booking counts, sales / provisioned conversion (not paid conversion or retention). First invoice day difference is approximate (UTC registration date vs invoice calendar date), excludes negative dates, shows sample count; deletion/backdating can affect historical evidence. No personal identifiers returned, no new DB writes or migration, no demo inclusion. Pre-submit events are not recorded; separate privacy-reviewed telemetry workstream needed for visit starts and step-level abandonment. No production query or deploy; CI, independent review and staging SQL and UI verification required.
