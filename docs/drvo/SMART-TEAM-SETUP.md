# Smart Team Setup (#358)

Extends salon /setup/team using the existing scoped onboarding transaction and employee creation model. Optional initial hourly/daily/monthly pay rate and employment type (freelance cannot be monthly), available only with the payroll app. Booking eligibility choice only with booking installed. Duplicate existing employees are not updated; existing unassigned employees with explicit new settings are rejected for review. The new team panel lists current branch employees and links to canonical HR, branch schedule, and account/permissions administration. No commission plan edits, effective-dated schedule writes, user creation, historical payroll or automatic financial posting. Excel import explicitly omitted. No production access. CI and staging smoke required: with/without installed apps, all three pay methods, invalid values, duplicate/retry, same branch vs other tenant, mobile/desktop, and legacy CUT unaffected. Human merge only.
