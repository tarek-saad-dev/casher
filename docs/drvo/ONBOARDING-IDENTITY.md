# Onboarding identity (#356)

Optional salon setup screen /setup/identity, reachable from the guarded setup layout. Uses existing authenticated tenant brand API and optimistic revision; preserves branch/contact/timezone/origins and does not mutate tenant IDs, public booking or operating data. HTTPS logo link with explicit preview; no upload or remote server fetching. Existing same-origin logos are retained; palette and example receipt/workspace preview use draft values. Not all app screens necessarily consume brand colors. Direct upload, actual receipt printer verification and universal theme propagation are separate tasks. CI and staging review required, including tenant isolation, conflicting revision and mobile/desktop. No database migration, production access or deployment.
