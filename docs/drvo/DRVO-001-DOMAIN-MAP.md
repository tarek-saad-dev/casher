## How to read this map

- **Target DRVO Module**, **Classification**, and **Migration Action** are **provisional** / **candidate** labels for DRVO-002 — not decisions.
- **Migration Action** vocabulary: `KEEP` / `EXTRACT` / `ADAPT` / `REPLACE` / `RETIRE` (provisional).
- **EXTRACT ≠ separate database:** see EXTRACTION-AUDIT §14 LEVEL 1–5. Map EXTRACT means provisional capability separation, not evidenced LEVEL 4.
- **Classification**: Platform Core / Shared Domain / Independent App / Industry Extension (provisional).
- **Risk**: Low / Medium / High / Critical — based on VERIFIED CURRENT STATE coupling unless noted.
- Evidence labels appear in Risk notes where a claim is incomplete.

## Notes on isolation (VERIFIED CURRENT STATE)

- **Most isolated relative to peers:** Messaging under `src/modules/messaging`; booking **scheduling** engines under `src/lib/booking`.
- **Least isolated:** Floor `/operations` flow-board; nightly close; `TblCashMove` + **`InsCashMoveSales` trigger**; employee ledger dual-write; booking **conversion**; session shell; sale update/delete CashMove asymmetry vs create.
- **Module maturity (not fully isolated):** Attendance has substantive command/domain services still calling `src/lib/hr`. Operations has real day/shift lock + mutation TX infra. `business-day` / `transfers` / `availability` remain closer to Phase-A facades. `src/modules/README.md` is stale vs HEAD for attendance/operations.
- **Auth:** cookie + RBAC pages + `TblUserBranchAccess` + day/shift gates; public booking uses tokens; staff booking non-convert routes often weaker than POS.
- **Undecided (DRVO-002):** Day/Shift owner; CashMove owner; extraction LEVEL per domain; Booking convert cross-system contract if scheduling moves first; stronger public customer auth beyond possession/token (see EXTRACTION-AUDIT §16.3).
- **Auth note:** Staff RBAC/branch ACL ≠ public customer ownership (possession / bookingAccessToken today).
- **Concurrency note:** Slot claims default off; reschedule = single SERIALIZABLE TX + applocks; claims enforce optional (EXTRACTION-AUDIT §17 / §17.1).
