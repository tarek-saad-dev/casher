# Application-bound trial issuance

Staff CHECK/ISSUE derives the account, legacy client, program revision and branch from an accepted application. It shares the publication lock and revalidates latest publication and the existing trial evaluator inside one serializable transaction. New drafts must be explicitly published before further requests can issue against them; current latest-draft mismatch blocks old requests conservatively. Issuance and a unique fulfillment link commit together. An already fulfilled request cannot issue again. The existing independent staff-only trial sandbox remains separate; no public grant. TRIAL_ISSUED is a historical request status, not proof of current membership validity. Requires application, publication and separate application-issue flags, staging only. No financial grants, live deployment, or production DDL. Requires dedicated integrated SQL acceptance and website contract update.
