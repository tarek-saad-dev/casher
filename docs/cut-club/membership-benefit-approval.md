# Benefit approval (staging only)

APPROVE pins the current publication, latest program draft and exact latest benefit draft revision. The shared serializable publication lock and transaction catalog read reject stale approvals, missing or unsuitable service IDs, out-of-scope program branches and fixed prices above the current global catalog price. The catalog snapshot is an audit artifact, not an authorization. REVOKE appends a new event, including for superseded approvals. A newer unapproved benefit draft does not replace an existing approval. A new program draft or withdrawn/superseded publication makes the approval noncurrent; republishing requires explicit new approval. No customer display, no actual usage tracking or invoice mutation, no coins, no production migration. Future POS enforcement must verify current price, branch eligibility, account/proof, usage and stacking policy in the invoice transaction. Separate default-off staging flags.
