# Benefit catalog and quote preview

Admin draft editor reads tenant-scoped active explicitly service-classified rows from TblPro/TblCat, using existing public booking policy to exclude internal, retail, test and invalid-duration/price entries. The shared SPrice1 is a global catalog price, not branch-specific or invoice-final price. No schema ensure calls, no production or financial write. Single-line integer-minor-unit preview rounds percentage discounts down, rejects price increases and over-limit simulated usage. UI uses one unit with zero previous usage explicitly. Service IDs can still be saved as proposed drafts through the underlying API; publication must enforce authoritative server-side service and branch eligibility and valid prices. No real membership/usage lookup, no POS authorization, no financial mutation. Exact staging flag and DB/login required.
