# Membership policy preview — phase 1

Separate special membership eligibility from account moderation and existing loyalty tiers. GENERAL, STUDENT, DOCTOR and COMPANY are draft categories, no default entitlements or discounts. Administrator can simulate disabled/enabled, branch scope, minimum completed visits, verified category evidence, expiry and exact partner code. Empty branch scope fails closed. The HTTP endpoint accepts hypothetical facts only; it never reads/writes actual customer, wallet, invoice or membership data. No Google review condition or financial entitlement is supported. The page does not save policy settings. Next: reviewed persistent tenant-scoped program and evidence schema (after 027 is applied and next migration ID confirmed), audited staff approvals, source verified visits from invoices, website read model, and separately approved discount rules.
