# Membership benefits: configuration draft only

Four proposed benefit kinds: percentage discount in basis points (10000 = 100%), free service (zero value), fixed price in EGP minor units, and integer bonus coins. Every rule targets exactly one service ID, an allowed subset of program branches, and explicit per-membership and per-invoice use limits. At most one rule per service in a draft, maximum 20 rules. These are conservative pilot constraints, not finalized commercial policy. No default discounts, no financial writes, no public display, no automatic grant. Saving requires the latest program draft revision, revision conflict protection, audit reason and staff ID. Service IDs are proposals and must be validated against the authoritative tenant service/price/branch catalog before any publication; benefit rule publication, stacking, qualifying paid visits, invoice-time enforcement and cancellation/usage ledger are still outstanding. Exact staging DB/login, separate off-by-default flag; no live schema deployment.
