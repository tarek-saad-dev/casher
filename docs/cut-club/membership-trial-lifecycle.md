# Staging membership trial lifecycle

Admin-only CHECK/ISSUE API uses latest saved draft revision, current linked account/phone, current evidence, branch scope, and the existing loyalty TotalVisits aggregate (not independently verified paid invoices). The draft is evaluated as if enabled solely for a trial. Explicit ISSUE creates a versioned nonfinancial trial record; current trial duplicate is rejected, expired or invalidated trial can be reissued with expected revision. Validity may not exceed proof expiry or a provisional maximum 365 days; this is a pilot safety cap, not an approved commercial membership term. Reads recompute effective status for the selected branch; no production publication, benefits, public website, actual application flow or invoice enforcement. Exact staging DB/login and flag required. Requires reviewed staging schema and later approval. No production schema or deployment performed.
